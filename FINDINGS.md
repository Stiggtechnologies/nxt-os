## Wiring checks that passed
- Every `/api/...` path the front end uses matches a backend route, including the catch-all `{*rest}` routes in `/api/company-ledger` (open, opening-balances) and the multi-line `.route(` calls (nixon reviews decide, dtmax test-copy clients).
- Every `data-go` dock target has an entry in `APPS`. The shell handles every `postMessage` type the apps send (`view`, `open-app`, `company`, `signed-out`).
- Every app index.html loads `/nxt/ui.js` and `/nxt/company-switcher.js`.
- Live site: `/`, `/welcome.html`, `/demo.html`, `/sign/`, `/widget.js` and all 9 `/apps/*/` return 200. Every static `src`/`href` asset is 200. The live switcher, bridge, ledger.js, firm.js, shortcuts.js and qb-navigation.json are byte-identical to main. Protected APIs return 401 when signed out (as expected). The only 404 was `/favicon.ico`.
- `node --test` passes for every `tests/*.test.mjs` before and after the change. Rust tests were not run.
