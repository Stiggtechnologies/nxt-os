# Figures available only in preserved PDFs

Five exact existing PDFs supply six printed-line observations each for four
owner-years with no matching native context in the pinned import-time inventory.
The two 2010 byte versions remain separate. This evidence does not create a
native return, family context, calculated tax case or preferred financial copy.

The `preserved-pdf-figures` namespace has its own closed profile, immutable bodies,
POST, ordered readback and summary. It does not extend the 2,527 cached-export
observations. Its eight-field PDF descriptor binds the existing uploaded record;
the old PDFs have no cached-export provenance. Import and record reads check the
actual existing PDF blob hash and byte length, one document at a time. They do
not write PDF metadata or bytes.

Each ordered observation retains the actual historical printed code, requested
canonical code, exact cents/decimal when supported, and original candidate JSON.
The six explicit historical code bindings have independent authority and require
the actual year/code/label/cell evidence. No general numeric code conversion or
tax arithmetic supplies missing values. Blanks and held states remain null.
Original duplicate glyphs and agreeing carryforward occurrences remain evidence,
not additional amounts. Source geometry floats stay inside byte-preserved JSON
strings. Full descriptor hashes admit only independently closed source records.

T1 roster years are a read-time union. Affected rows expose
`native_historical_years`, `preserved_pdf_figure_years` and `pdf_only_years`;
stored profiles and native indexes are unchanged. The original 5,856 client rows
gain only four owner-year selections. A paper-only year initially opens the
Preserved PDF figures category while all other source categories remain visible.
Each PDF copy shows its own amounts and exact SHA/page links. Native totals and
the native comparison selector retain their source distinction.

Absence is qualified to the pinned audit. Later legitimate native recovery does
not invalidate the preserved observations; the derived native/paper distinction
updates from the actual indexes. Source figures remain unapproved and filed-copy
status remains unverified.

POST accepts 1–5 records and returns integer created/replay/submitted counts in
the new scoped envelope. Ordered readback accepts 1–5 identities and supports
nullable missing records before import. Matching replays repair all derived
indexes after interrupted writes. A direct record read does not prove those
indexes are complete. The uploader must verify the final summary, client indexes
and derived roster years.

Private verification covers all five source records and PDF blobs, 32,744 native
history bodies, 2,527 cached observation bodies, 5,856 profiles, the original six
summary responses, exactly four derived roster additions, three interrupted
index phases and later native recovery. Actual source fixtures and values stay
outside Git.
