## Release and migration interpretation

The preparation foundation must be labeled with its scope and connector state wherever exposed. An app tile, source menu inventory, internal prepared state, hash chain or passing synthetic lifecycle test does not close source-product gaps. Existing DocuSign records remain authoritative; no source envelope/document migration has occurred. This stream must not block or be conflated with the separate QuickBooks parallel-source archive release.

Before relying on a replacement signing workflow, add and test every required missing capability, then independently assess the actual legal, security, evidence-preservation and recipient-authentication requirements using current authoritative sources. Operational rollout and financial cutover remain subject to NXT's existing reconciliation, recovery and human review gates.
