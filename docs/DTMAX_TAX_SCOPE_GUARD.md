# Exact tax scope guard

2025 Quebec is not implemented by the independent engine. It formerly passed the shared jurisdiction check and fell through to Alberta. The dispatcher now checks program + year + jurisdiction together and has an explicit Alberta branch. No formulas or supported scopes were added. Existing bounded 2025 Alberta/Ontario/other provincial workpapers and the implemented narrow 2026 Quebec workpaper remain separate.

Unsupported preparation drafts remain saveable. Calculating one returns blocking diagnostics with no calculated lines or totals. A saved unsupported-scope snapshot cannot be replayed as current through an idempotency key, reviewed, approved, used to prepare T183 authorization, confirmed by the Filing Desk, or recorded as externally filed. Review and Filing Desk gates independently check the current scope; a historical `supported: true` flag is insufficient. Existing filing confirmations do not suppress the queue blocker or satisfy a launch test once their scope is unsupported.

The response-only `current_scope_supported` qualifier is included in individual return and list responses and native packages. It means only that a program/year/jurisdiction dispatcher exists; scenario-specific checks and diagnostics still decide whether a calculation is supported. List readiness is false for unsupported scopes. Workpaper, guided-review and printed HTML views warn about historical unsupported results; guided refund/ready meters cannot treat them as current.

Historical snapshots, amounts, hashes, reviews, filing records and audit events are preserved. This change does not recalculate, delete or silently change any saved result or legal record. JSON exports intentionally retain those historical bytes alongside the new qualifier. Existing `approved` or `filed` status is historical metadata, not current eligibility. Previously printed/downloaded files and external records cannot be retroactively relabeled; operators must assess affected historical use separately. A new calculation requires an editable draft and a fresh idempotency key; filed workpapers retain the existing immutable-history/amendment rules.

Synthetic regressions cover 2025 QC, unsupported years/jurisdictions, supported AB/BC/ON and 2026 QC, plus valid-hash simulated old QC snapshots through API read/list/package/print, replay, review/approval/recorded-filed, T183 and Filing Desk blockers. No client records, government endpoints or vendor runtime are used. This is a correctness guard, not certification or full DT Max parity. Catalog/documentation expansion remains separate.
