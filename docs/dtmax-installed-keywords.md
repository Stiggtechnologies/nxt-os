Saved T1 data-entry fields display names from the installed English DT Max dictionary for that exact source year. Numeric field IDs, occurrence order and original values stay visible; source form codes keep their original numbers.

The 19 tables cover 2005 and 2009–2026 with 47,692 names. Each public table is client-free and pinned by SHA-256 in the viewer. A missing, changed or unavailable table falls back to numeric IDs. Original T3 reader holds never receive T1 labels. No nearest-year fallback is used.

The provenance JSON records the original installed carrier, record table, name table and extracted mapping hashes. Static inspection established that KWDICT_raw.data_id becomes KKeyword.KeywordID; the original CFRecordReader and saved export reader both retain that ordinary keyword ID as Q.z. Names were read as fixed 19-byte CP850 strings. No vendor code or activation is needed to use these generated tables.

This establishes label lookup only. It does not establish native form titles (including form176), enum option meanings, tax-line mapping, YearSwitch applicability, value normalization or approved financial values. Installed-year carriers are the authority observed; their labels are not proof of unchanged wording in every historical installation. Complete original source bytes remain available through the unchanged download.
